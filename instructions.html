How to use your README on GitHub

Your README.md should be downloading now. Follow these steps to display it on your GitHub profile.

  1. Create a new GitHub repository with the exact same name as your GitHub username (e.g., if your username is octocat, name the repo octocat).
  2. Make sure the repository is Public.
  3. Check the box for "Add a README file" when creating it, OR add one afterward.
  4. Replace the contents of that repository's README.md with the file you just downloaded.
  5. Commit the changes — your GitHub profile page will now display this content automatically.
